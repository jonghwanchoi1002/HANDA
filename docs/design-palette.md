# HANDA 디자인 팔레트

의뢰자가 전달한 팔레트 이미지와 `MainF.dc.html`을 기준으로 전체 화면의 색상을 통일합니다. 디자인 도구의 `support.js`와 vendor React 런타임은 프로덕션에 포함하지 않습니다. 기존 Next.js 컴포넌트와 회원 권한·작성·승인 흐름을 유지합니다.

| 토큰 | 색상 | 용도 |
| --- | --- | --- |
| `--cream` | `#F7EFDF` | 기본 배경, 입력·카드, 어두운 면의 글자 |
| `--sage` | `#DDE1D6` | 소개 섹션, 안내 면, 아바타·사진 자리 |
| `--ink` | `#231F1C` | 본문, 헤더·푸터, 주요 버튼 |
| `--terracotta` | `#B4572B` | 메인 참가자 이야기 섹션의 큰 포인트 면 |
| `--terracotta-deep` | `#A94A27` | 밝은 배경의 링크·강조 글자, 포커스, 오류 안내 |
| `--brass` | `#CDAF84` | 어두운 면의 강조, 장식·선, 선택 영역 |
| `--logo-red` | `#D92D23` | 로고 전용 예약 색상 |

색상 정의는 `src/app/globals.css` 한 곳에 둡니다. 일반 텍스트·옅은 선·그림자·오버레이는 위 색상만 `color-mix()`로 혼합하거나 투명도를 적용합니다. 임의의 회색·초록·순백색을 별도로 추가하지 않습니다. 정보 전달은 상태 이름과 안내 문구를 유지하며 색상에만 의존하지 않습니다.

크림 위의 작은 강조 글자는 Terracotta Deep을 사용합니다(대비 약 4.97:1). 세이지 면의 작은 글자는 Ink로 표시합니다. Terracotta 면 위의 작은 링크는 Deep 면을 별도로 두어 읽을 수 있게 하고, 키보드 포커스를 유지합니다.

공개 페이지뿐 아니라 로그인·내 계정·글 편집·콘텐츠 관리·회원 관리·각종 팝업까지 같은 토큰을 사용합니다. 로고는 제공된 벡터를 변경하지 않고 `public/brand/handa-logo-cream.svg`에 보관하며 헤더와 공개 페이지 푸터에서 사용합니다. 헤더의 고정 높이와 공통 내비게이션 구조는 유지합니다.

## 참고 자료와 이번 범위

전체 팔레트와 제공 로고를 적용하고, 메인을 큰 히어로·소개·멤버 3열·위키/정기모임 후기 2열 카드·참가자 이야기 순으로 구성합니다. 카드는 전체를 클릭해 해당 페이지로 이동하며 모바일에서는 한 열로 배치합니다. 공개된 멤버 소개만 사용하고 실제 참가자 추천사는 공개 동의를 반영한 기존 공개 조회를 사용합니다. 메인 HTML은 시각적 참고 자료로만 사용하며 본문과 DB 콘텐츠를 자동 덮어쓰지 않습니다. HTML이 참조하는 `assets/fd48c7faa73a2ca1773dcf569e0e669c.jpg`는 업로드된 파일 목록에 포함되지 않았습니다. 대화에 표시된 사진 대신 임의의 사진을 사용하거나 존재하지 않는 경로를 연결하지 않습니다. 히어로와 정기모임 후기 카드의 사진 레이어는 `src/data/home-artwork.ts`의 `homeMainPhoto`로 연결합니다. 현재 값은 `null`이므로 사진 요청 없이 잉크 배경을 표시합니다. 해당 JPG를 파일로 전달받으면 정적 자산으로 추가하고 URL을 설정합니다. 사진이 없는데 연결된 것처럼 표시하거나 생성 이미지로 원본을 대체하지 않습니다. 상단 메뉴는 홈을 포함한 모든 페이지에서 잉크 배경을 항상 유지합니다. 히어로는 메뉴 아래에서 시작하며 메뉴 높이와 위치는 고정합니다.

색상 변경에는 환경 변수·추가 패키지가 필요하지 않습니다. 메인 문구 교체에는 아래 009 데이터 마이그레이션을 사용합니다. 디자인 브랜치는 앞선 `fix/publishing-account-flow`의 수정도 포함합니다.

## 메인과 About 편집

메인 초기 문구는 예시의 ‘혼자 고민하던 일을, 함께 풀어가는 곳.’과 설명으로 맞춥니다. `009_home_design_copy.sql`은 이전 기본 예시 문구와 일치하는 필드만 교체하며 관리자가 직접 수정한 문구는 보존합니다. 변경 시 리비전을 증가시키고 콘텐츠 감사 기록을 남깁니다.

관리자는 **내 계정 → 콘텐츠 관리 → 홈 소개 → 수정**에서 메인 제목·설명, About 소개 제목, 01·02·03 각각의 제목과 설명을 수정할 수 있습니다. 보충 요약·본문은 선택 사항이며 비워 두면 예시처럼 소개 제목과 3개 항목만 표시합니다. 새 항목은 기존 JSON에도 기본값을 적용하므로 구형 콘텐츠가 오류를 일으키지 않습니다.

개발 DB에 `npm run db:migrate`를 실행한 뒤 확인합니다. 추후 운영 배포 시에는 운영 DB에도 009를 적용해야 하며 이번 작업에서 운영 DB를 직접 변경하지 않습니다.

`010_home_reference_hero_copy.sql`은 요청에 따라 기존 WIP/테스트 문구를 포함한 메인 제목·설명을 예시 문구로 한 번 교체합니다. About의 사용자 편집 내용은 보존하며 감사 기록과 리비전을 남깁니다. 이후 관리자 저장은 새 문구를 정상적으로 변경할 수 있습니다.
